# テスト仕様書

最終更新: 2026-10-16

## 1. テストの進め方

| 項目 | 内容 |
|---|---|
| 方法 | 手で画面を操作して確かめる（手動テスト） |
| 環境 | バックエンド（3000）とフロントエンド（5173）を両方起動。Chrome |
| 使う道具 | Chrome DevTools（Network：通信、Console：ログ、Throttling：通信をわざと遅くする） |
| テストデータ | バファリンA（解熱鎮痛薬／頭痛・発熱・生理痛）、新ビオフェルミン（分類なし＝NULL／便秘・下痢） |
| 結果の書き方 | ✅ 合格 / ❌ 不合格 / − 未実施。不合格なら、気づいたことを備考に書く |

**正常系**とは、普通の使い方で正しく動くかの確認です。
**異常系**とは、わざと失敗させたときに、困らない動きをするかの確認です。

## 3. 既知の不具合・観察メモ

| 内容 | 状態 |
|---|---|
| Backspace で「頭痛」→空にしたとき、一度だけ「見つかりませんでした」になった。古い返事が新しい返事を上書きした（返事の追い越し）疑い。再テストでは再現せず | 経過観察。デバウンスで起きにくくなった |
| 開発モードでは、エラーが2セット出る | 不具合ではない（React の StrictMode が、開発中だけ useEffect を2回動かすため） |
